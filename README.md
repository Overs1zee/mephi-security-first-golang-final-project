# Модуль фитнес-трекера

Учебный модуль на Go для парсинга данных о физической активности пользователя (тренировках и дневных прогулках), расчёта дистанции, средней скорости и потраченных калорий.

## Архитектура проекта

Проект организован в соответствии со стандартной структурой Go (`cmd/` и `internal/`):

- `cmd/tracker` — точка входа приложения, демонстрация работы пакетов на тестовых наборах данных.
- `internal/spentenergy` — расчёт дистанции, средней скорости и сожжённых калорий при беге и ходьбе с валидацией входных параметров.
- `internal/personaldata` — структура `Personal` (имя, вес, рост пользователя) и метод вывода профиля.
- `internal/trainings` — структура `Training` (со встроенным `personaldata.Personal`), парсинг строк вида `"3456,Ходьба,3h00m"` и формирование отчёта о тренировке.
- `internal/daysteps` — структура `DaySteps` (со встроенным `personaldata.Personal`), парсинг строк вида `"678,0h50m"` и формирование отчёта о дневной прогулке.
- `internal/actioninfo` — интерфейс `DataParser` и полиморфная функция `Info()`, обрабатывающая любые типы активностей через единый контракт.

## Запуск приложения

```bash
go run ./cmd/tracker
```

## Тестирование проекта

Рядом с файлами, которые вы будете редактировать, находятся файлы с суффиксом `_test.go`. В них содержатся юнит-тесты, проверяющие корректность вашей реализации. Эти тесты автоматически запускаются на GitHub. Чтобы работа была зачтена, ваш код должен успешно проходить все тесты. Обратите внимание: изменять содержимое тестов запрещено.

Вы можете запускать тесты локально, выполнив следующие команды в корневой директории репозитория:

```bash
go mod tidy
go test -v -race ./...
```
